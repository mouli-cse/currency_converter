# Currency Converter

A simple browser-based currency converter built with HTML, CSS, and JavaScript.

## Features

- Convert between multiple currencies
- Live exchange rate updates using a predefined rate list
- Responsive user interface
- Easy to run locally in any browser

## Project Files

- `currency_converter.html` — page structure
- `currency_converter.css` — styling
- `currency_converter.js` — conversion logic
- `currency_converter_list.js` — currency data and rate definitions

## How to Run

1. Open `currency_converter.html` in a web browser.
2. Select the source currency and target currency.
3. Enter the amount to convert.
4. Click the convert button to see the result.

## Notes

This project uses a static currency list and exchange rates for demonstration purposes. If you want to use live exchange rates, you can integrate a real API later.
